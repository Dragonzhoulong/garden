# 学习咒语清单

| 场景分类            | 咒语示例                                 | 功能说明               |     |
| --------------- | ------------------------------------ | ------------------ | --- |
| 📝 测验 / 练习      | `quiz me with [主题]`                  | 出题测验               |     |
|                 | `test me on [主题]`                    | 给我测验题              |     |
|                 | `drill me on [主题]`                   | 快问快答式练习            |     |
|                 | `make flashcards about [主题]`         | 制作抽认卡              |     |
|                 | `give me practice problems for [主题]` | 给我练习题              |     |
| 🎓 讲解 / 教学      | `teach me [主题]`                      | 系统讲解，像课堂一样         |     |
|                 | `explain like I'm 5 (ELI5) [主题]`     | 小孩子能懂的解释           |     |
|                 | `step by step solve [题目]`            | 一步步推导过程            |     |
|                 | `explain [主题] with examples`         | 边讲边举例子             |     |
|                 | `compare [概念A] vs [概念B]`             | 对比讲解               |     |
| 👩‍🏫 模拟 / 角色扮演 | `interview me on [主题]`               | 模拟面试               |     |
|                 | `act as my [科目] tutor`               | 扮演我的老师             |     |
|                 | `roleplay [场景]`                      | 场景对话（如点餐、面试）       |     |
|                 | `be my [技能] coach`                   | 扮演教练（如 math coach） |     |
| 🎨 创意 / 表达      | `summarize [主题] as a poem`           | 用诗歌总结              |     |
|                 | `explain [主题] with an analogy`       | 用类比解释              |     |
|                 | `turn [概念] into a story`             | 讲成小故事              |     |
|                 | `make a table of [主题]`               | 整理成表格              |     |
|                 | `visualize [过程] step by step`        | 图解/流程化说明           |     |
